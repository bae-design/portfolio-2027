03Narrative action / console

Wake Cycle

Role

UX / onboarding

Year

2025

With

Level design & audio

Output

First-hour flow

No slideshow. The room is the tutorial; the UI only confirms a verb the world already taught.

Problem

The original first hour stacked six input callouts before the player had a reason to care. Completion was high; memory of the verbs was not.

Approach

We cut chrome until each prompt mapped to a physical action already staged in the level: a door, a radio, a ledge. The UI appears only after the player has started the gesture, then leaves. Fail states are diegetic — a locked door, not a toast.
